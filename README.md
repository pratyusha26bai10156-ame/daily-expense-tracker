# Daily Expense Tracker

## Project Title
Daily Expense Tracker - Personal Finance Management

## Overview of the Project
CLI based Python app to track daily expenses, categorize spending, and show analytics. Works offline with local file storage.

## Features
- Add, View, Delete, Update expenses
- Category-wise tracking
- User management
- Analytics
- Input validation
- Local storage

## Technologies/Tools Used
Python 3.8+,standard library(csv,datetime,os)

## Steps to Install & Run the Project
1. git clone https://github.com/pratyusha26bai10156-ame/daily-expense-tracker.git
2. cd daily-expense-tracker
3. python main.py

## Instructions for Testing
python test_basic.py
